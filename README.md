# Inventory Management System (IMS)

A simple inventory management system built using Python. This project includes a GUI interface powered by Tkinter and uses SQLite for data storage.

## Features
- Add, delete, and search for items.
- View and refresh the inventory table.
- Customizable logo and easy-to-use interface.

## Requirements
- Python 3.6 or later
- Pillow library (`pip install pillow`)
